# 范围

&emsp;&emsp;专题制图系统本质是一个多技术手段综合支撑下的在线式专题地图数据制图系统，其最终目标是：基于已有的空间地理大数据和海量业务专题数据，利用web3.0框架支持下的专题制图技术，将空间数据和业务数据结合，基于自主研发的数据挖掘模型模块的分析结果，实现专题地图制图过程的动态化、制图符号表达的动态化和动态地理现象的制图表达，最终以综合可视分析的专题地图形式与空间地理大数据平台集成，为其他省政府部门提供在线服务。具体表现为基于浙江省空间地理大数据库，结合各级政府或权威部门或机构公开发布的各类统计数据，如社会、经济、自然资源与环境、人口数据等等，通过建立专家制图知识库、专题地图符号库，结合动态专题统计图表、动态专题地图制图和地理统计模型等数据可视化和数据空间化等技术手段，设计建立一个多技术手段综合支撑下的专题地图在线制图系统，为用户提供规范化、流程化、定制化的专题制图服务。也可通俗理解为是适合各类政府部门用户使用的地图时空数据可视化分析工具（Domain Geographical Information Visulization Aanlysis Tool），能够为不同部门提供个性化的专题地图数据制图功能，推动整个浙江省空间相关的社会经济统计信息资源的有效管理和利用。
