SDK 使用方式介绍

二维矢量瓦片地图API是一套 JavaScript 语言开发的地图应用编程接口，兼容多种系统平台，移动端、PC端一体化设计。 JS API 提供了满足绝大多数开发者对底图加载、注记加载、要素拾取、要素过滤、图层控制、注记避让及图形绘制的需求，同时也提供了矢量瓦片地图服务、矢量瓦片注记服务、获取图层列表服务、图元拾取高亮服务和动态图例信息获取等众多开放服务接口。

二维矢量瓦片地图SDK for Leaflet （最新2.1.6）API套插件，可帮助您在网站中构建功能丰富、可交互、可定制、可查询等高交互的地图应用。支持PC端、移动端、基于浏览器的底图应用开发，且支持HTML5 特性地图开发。支持HTTP1.0、HTTP2.0和HTTPS等多种超文本传输协议。

二维矢量瓦片地图API拥有完善的文档体系，系统学习地图和服务接口调用请前往开发中心，快速了解 JS API 的全部核心能力请参考示例代码，使用遇到问题可查看常见问题。
