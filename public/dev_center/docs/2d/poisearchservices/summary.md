- **web 服务API**

   POI搜索服务API是通过 HTTP 协议访问远程服务的接口，提供多种查询POI信息的能力以及统计能力，包括POI关键字搜索，在关键字基础上做矩形查询、缓冲区查询，获取POI关键字建议，根据ID获取文档详情，POI关键字区域分类统计服务以及最近POI查询。

- **POI搜索服务特性**

    1)扩展全要素智能搜索
    <br/>在地名地址、POI查询的基础上扩展支持AOI查询，实现点、线、面全要素搜索，并提供智能提示、聚合查询等辅助能力。
   
    2)支持多样化空间查询
    <br/>支持关键字查询、分类查询、区域查询、缓冲区查询等多种查询方式，满足精确匹配、模糊查询、周边查询等不同的应用场景。
 
- **核心服务能力**
 
    1）. POI查询服务；
   
    2）. POI关键字建议服务；
   
    3）. 根据ID获取文档详情服务；
   
    4）. POI关键字区域分类统计服务；
   
    5）. 最近的POI获取服务.
