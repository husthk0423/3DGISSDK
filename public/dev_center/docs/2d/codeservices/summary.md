- **web 服务API**

   地理编码 API 是通过 HTTP 协议访问远程服务的接口，提供从地址到经纬度坐标或者从经纬度坐标到地址的转换服务，用户可以使用C# 、C++、Java等开发语言发送请求且接收JSON、XML的返回数据。

- **地理编码服务特性**
   
    1)高效的地址匹配引擎
    <br/>支持人口、法人、经济等基础、行业数据的批量地址匹配，以接近实时处理的效率提供地理编码服务，实现人、财、物的快速落地。
    
    2)综合的地理编码能力
    <br/>综合多种定位服务，具备地名地址、POI、建筑数据、院落数据、行政区划数据等综合地理位置编码和逆编码能力分层管理按需构。
 
- **核心服务能力**
 
     1）. 单一匹配服务；
   
     2）. 匹配源文件上传；
   
     3）. 批量匹配服务；
   
     4）. 批量编码结果；
   
     5）. 批量编码结果元数据查看；
   
     6）. 批量编码结果重新匹配；
   
     7）. 匹配结果下载保存.
